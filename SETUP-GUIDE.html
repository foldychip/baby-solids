🥣 Setting up cloud saving (Google Sheets)

Your app already saves on your phone automatically. These steps connect it to a Google Sheet so your progress syncs across phones and isn't stuck on one device. It's a one-time, ~5-minute setup. You only need a free Google account.

⚠️ Reminder: the food and allergen guidance in the app is general information, not medical advice. Please confirm your baby's plan — especially allergen timing — with your pediatrician.
1Create a spreadsheet.
Go to sheets.google.com, sign in, and click Blank spreadsheet. Name it anything, like "Baby Solids".
2Open the script editor.
In the spreadsheet's top menu, click Extensions → Apps Script. A new tab opens with a code box.
3Paste in this code.
Delete everything already in the code box, then paste all of this: 
var SHEET_NAME = "Data";

function getSheet_() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SHEET_NAME);
    sh.getRange(1, 1).setValue("littleBitesData");
  }
  return sh;
}

function doGet(e) {
  try {
    var sh = getSheet_();
    var cell = sh.getRange(2, 1).getValue();
    var data = cell ? JSON.parse(cell) : null;
    return json_({ ok: true, data: data });
  } catch (err) {
    return json_({ ok: false, error: String(err) });
  }
}

function doPost(e) {
  try {
    var body = JSON.parse(e.postData.contents);
    if (body.action === "save") {
      var sh = getSheet_();
      sh.getRange(2, 1).setValue(JSON.stringify(body.data));
      sh.getRange(2, 2).setValue(new Date());
      return json_({ ok: true });
    }
    return json_({ ok: false, error: "unknown action" });
  } catch (err) {
    return json_({ ok: false, error: String(err) });
  }
}

function json_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
4Save & deploy.
Click the Deploy button (top right) → New deployment. Click the gear ⚙️ next to "Select type" and choose Web app.
5Set the permissions.
In the dialog set:
  • Execute as: Me (your email)
  • Who has access: Anyone
Then click Deploy. Google will ask you to authorize — click through, choose your account, and if it warns "Google hasn't verified this app" click Advanced → Go to (your project) and Allow. (It's your own script talking to your own Sheet — that warning is normal for personal scripts.)
6Copy the link.
It gives you a Web app URL ending in /exec. Copy it.
7Paste it into the app.
In Little Bites, open the ⚙️ Setup tab, paste the link in the Google Sheet link box, and tap Connect. Done! On your partner's phone, open Setup and paste the same link so you both share one plan.
💡 Where's my data? Open your spreadsheet anytime — a tab called Data holds your saved progress, with a timestamp of the last save. You can keep the app and the Sheet forever, free.
